DBOS operator installed as release {{ .Release.Name }} in namespace {{ .Release.Namespace }}.

1. Create the DBOS API key secret (if not already present):

   kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.apiKey.existingSecret }} \
     --from-literal={{ .Values.apiKey.key }}=<your DBOS API key>

   The operator pod will not start without it.

2. Deploy applications as DBOSApplication resources (kubectl explain dbosapplication.spec).

3. To autoscale an app, point a KEDA metrics-api trigger (or any HPA external
   metrics source) at:

   http://{{ include "dbos-operator.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}/apps/<app>/autoscale

   using valueLocation "desiredExecutors".
